# 重构为最简商户接入 showcase(resources JSON 配置版,终稿)

## 配置方式
- SDK JSON 配置文件:**`src/main/resources/config/wopSdkConfig.json`**(随 jar 打包),值取自你给的样例:
  `serverRoot=https://openapi-hw.10000da.vip:443`(网关测试环境域名)、`appKey=app_b06s4hi87frpn2et`、`suite=WOP-RSA2048-SHA256`(默认 2048)、`expiredSeconds=1800`、TEST-ONLY 商户私钥/平台公钥、`httpClient` 10000/30000/3;
- 客户端:`WopClient.fromConfig(WopSdkConfigLoader.load("classpath:config/wopSdkConfig.json"))`;
- 无 application.yml;**所有 Controller 接口均为 POST、参数统一放 JSON body**;path 必填。

## 删除
- `mock/` 整包、`demo/` 整包、`web/WopCallbackController.java`、`service/MerchantOrderService.java`、`web/ApiResult.java`(重写)
- 根目录 `config/`(生成物与模板)、`keys/`、`application.yml`
- `.gitignore` 同步精简

## 最终文件清单
1. **pom.xml**(不变):spring-boot-starter-web + wop-sdk-core:0.2.0 + wop-sdk-jdkhttp:0.2.0
2. **src/main/resources/config/wopSdkConfig.json** — 上述联调值
3. **config/WopClientConfiguration.java**(重写)— 仅一个 `@Bean WopClient`(classpath 加载 → fromConfig,加载期 fail-fast)
4. **web/dto/WopCallRequest.java** — 统一请求体:`{path(必填), level(L0/L2,缺省 L0), body(业务 JSON 字符串,可空=GET 语义), connectTimeout, readTimeout, appKey, serverRoot}`(override 类接口各自校验自己必填的字段)
5. **service/WopAppService.java**(新)—
   - `oneStop(req)` — 一站式 `client.execute(method, path, body, level)`;
   - `stepByStep(req)` — `buildRequest` → `TransportFactory.discover().create(serverRoot).send(draft)` → `verifyResponse`;
   - `overrideTimeout(req)` / `overrideAppKey(req)` / `overrideServerRoot(req)` — 分别以 `WopRequestOptions.builder()` 的 connectTimeout+readTimeout / appKey / serverRoot 单项覆盖,走 execute 的 options 重载;
   - **`preview(req)` — 预览接口**:`client.buildRequest(method, path, body, level)`(零网络 IO)返回 `RequestDraft.headers()` 与 `wireBody()`;level 缺省时一次返回 **L0 与 L2 两份**(L2 展示 `{"encrypted":"..."}` 信封与 `x-wop-encrypt` 头,L0 展示明文 body 与 digest 头);
   - 结果展开:非 2xx 抛 `WopGatewayResponseException`;`!ok()` 抛 IllegalStateException 带 reason;成功返回 `plaintextAsUtf8()`。
6. **web/WopDemoController.java**(新,全 POST)—
   - `POST /api/wop/one-stop`
   - `POST /api/wop/step-by-step`
   - `POST /api/wop/override/timeout`(connectTimeout/readTimeout 至少一项必填)
   - `POST /api/wop/override/app-key`(appKey 必填)
   - `POST /api/wop/override/server-root`(serverRoot 必填)
   - `POST /api/wop/preview` — 返回将发往网关的 header + body(L0/L2)
   - `GET /api/wop/config` — 当前生效配置(密钥打码,唯一 GET)
7. **README.md** — 最简接入说明(curl 示例含 preview)

## 验证
- `mvn compile` 通过;启动后 curl 实测 preview(L0/L2 的 header/body)与各调用端点(真实网关);网关侧拒绝时如实报告状态码与响应体。
